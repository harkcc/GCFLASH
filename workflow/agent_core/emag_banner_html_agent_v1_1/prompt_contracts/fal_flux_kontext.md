# FAL / FLUX Kontext Prompt Contract

Use for reference-preserving edits and scene adaptation when credentials exist.
This route is not allowed to invent product geometry.

## Stable Use

- Adapt a background around a real product.
- Remove clutter from a text safe zone.
- Generate a product-adjacent scene that will receive local text later.

## Failure Rules

Fail and switch to deterministic composite when:

- product body changes
- product appears twice
- generated labels conflict with source specs
- background produces fake badges, warranty icons or marketplace marks

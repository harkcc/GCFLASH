# Brand Frame Reference Matrix

Scope: only references related to brand-bearing frames, logo containers, corner badge/nameplate systems, and non-destructive product-image overlays.

## Keep

| Source | What it contributes | How it maps to EXCITED |
| --- | --- | --- |
| MDay Frame Overlay | Non-destructive frame/corner overlays over product imagery | Treat EXCITED frame as a final overlay layer. Do not bake it into the product image. |
| Logobean Frame Logo | Brand text/icon inside a deliberate frame | EXCITED should sit inside a frame/nameplate/rail, not float on an arbitrary color block. |
| Shutterstock brand logo frame taxonomy | Packaging-style logo frames, badges, labels, decorative borders | Useful shape library: framed label, crest, nameplate, sticker, border enclosure. |
| GraphicsFamily 3D metallic frame | Layered metallic frame/logo mockup | Use bevel, gloss, shadow, and material edges for tool/electronics category frames. |
| Envato 3D badge | Ecommerce badge/sticker material | Useful for raised sticker/seal treatment, but should be small and brand-led. |
| Freepik brand frame search | PSD-style badge/frame templates | Useful as shape inspiration only; do not reuse assets. |
| EXCITAT 41 crop sheet | Real seller-card benchmark | Keep logo top-right, slanted, high contrast, category-colored, tied to the border. |

## Reject / Use Only As Counterexamples

| Source type | Why not use directly |
| --- | --- |
| General product infographics | Too broad; focuses on text benefit layout, not brand border. |
| AI listing generators with generic scenes | Useful workflow reference, but visual output can become too clean or too lifestyle. |
| Large full-width hero banners | Too much page/banner logic, not marketplace main-image border logic. |
| Random cyber UI decorations | Looks like interface chrome, not ecommerce brand packaging. |

## Next Design Rules

- The brand module must be physically connected to the frame or top rail.
- The brand mark should have an intentional container: rail, nameplate, sticker, ribbon, or framed logo box.
- The outer border should remain thin enough for product area: current v4 uses 30 px.
- Avoid stand-alone shards, dots, dashed lines, cyber-corner widgets, and generic UI ornament.
- Preserve product fidelity: product goes under the frame; Image2 may blend background/contact shadows only; final overlay re-applies border and EXCITED.
